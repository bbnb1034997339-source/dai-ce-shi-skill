# 小墨导演

这是小墨导演 v6.3 skill，用于把小说、剧本或场景描述转换为中文电影分镜脚本。

## 内容

- `SKILL.md`：主分镜 skill，显示名为“小墨导演”，内部名称为 `xiao-mo-dao-yan`。
- `character-analyzer/SKILL.md`：配套的人物、道具和场景视觉分析 skill。
- `references/prefix-constraints.txt`：新版视频提示词前缀约束。

## 本地安装

将 `SKILL.md` 放入 Codex skills 目录下的 `小墨导演/` 文件夹。配套分析 skill 可放入 `character-analyzer/` 文件夹。
